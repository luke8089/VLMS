## **Database Structure**

Your database (`aura_edu`) has **15 main tables**:

### **Core Entities:**

1. **users** - Stores all users (admin, lecturer, student) with:
   - Authentication (email, password_hash)
   - Profile info (name, department, bio, phone, profile_image)
   - Face recognition data (face_encoding for biometric auth)
   - Password reset tokens

2. **courses** - Course catalog with:
   - Code, title, description, category
   - Lecturer assignment
   - Publication status

3. **enrollments** - Student-course relationships with:
   - Progress tracking (0-100%)
   - Status (active/completed/dropped)

4. **lectures** - Course content modules with:
   - Title, content, order
   - Duration and publication status

5. **materials** - Learning resources (PDFs, videos, documents) with:
   - File metadata (type, path, size)
   - AI-generated summaries and flashcards

6. **learning_progress** - Tracks student engagement with materials:
   - Progress percentage, time spent
   - Page tracking for PDFs
   - Completion status

### **Assessment System:**

7. **exams** - Assessments with:
   - Type (quiz/midterm/final/assignment)
   - Duration, marks, passing threshold
   - Proctoring settings and risk thresholds
   - Grade release control

8. **questions** - Exam questions with:
   - Type (MCQ/short answer/essay)
   - Options, correct answers, marks
   - Bloom's taxonomy difficulty levels
   - Explanations

9. **submissions** - Student exam attempts with:
   - Timing (started/submitted)
   - Scores and grading status
   - Risk scores and flagging
   - Face verification status
   - Approval workflow

10. **answers** - Individual question responses with:
    - Student answers and selected options
    - Correctness and scores
    - AI-generated feedback

### **Proctoring System:**

11. **violations** - Exam integrity monitoring:
    - Types (no_face, multiple_faces, eye_gaze, head_pose, phone_detected, tab_switch, etc.)
    - Severity scores
    - Screenshot and video evidence paths

12. **face_verification_logs** - Biometric authentication tracking:
    - Verification types (registration/pre_exam/liveness_check)
    - Confidence and liveness scores
    - Success/failure tracking

13. **face_admin_actions** - Audit trail for face-related admin actions

### **Additional Features:**

14. **live_classes** - Virtual class scheduling with:
    - Meeting links and platform info
    - Scheduled times and durations
    - Manual unlock capability

15. **user_analytics** - Activity tracking for insights
